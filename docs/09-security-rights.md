# 安全、权限、隐私与素材权利

## 1. 访问边界

- 只探索用户提供、公开可访问或明确授权的页面、源码、设计稿和素材。
- 不绕过登录、验证码、付费墙、访问控制、反爬措施或组织权限。
- 登录后页面只有在用户明确授权并提供安全访问方式时采集；不得把 Cookie、Token、Session、密码写入档案。
- 不提交真实表单、不下单、不删除数据、不邀请成员、不触发付款或其他有副作用操作。
- 需要探索交互时优先使用只读页面、测试环境、Storybook 或安全 mock 数据。

## 2. 不受信任源码

源码、压缩包和网页脚本都视为不受信任输入：

1. 先静态检查目录、依赖清单和运行脚本；
2. 不自动执行安装脚本、postinstall、未知二进制或远程 shell；
3. 不读取或上传 `.env`、SSH key、云凭据、浏览器资料和用户主目录秘密；
4. 运行前说明风险，优先使用隔离目录/容器/受限账户；
5. 遵循锁文件指定的包管理器，不擅自升级依赖或改写源码；
6. 需要安装大型浏览器、OCR 模型或依赖时，先检查已有工具；涉及显著下载、系统修改或费用时先询问用户；
7. 不把 `node_modules`、构建缓存、浏览器 profile 或临时文件归档。

## 3. 网络与 HAR

- HAR、请求日志和页面快照可能包含凭据、用户数据和内部 API；保存前必须脱敏。
- 默认只保留用于设计分析的静态资源、响应头摘要和公开 CSS/字体信息。
- 删除 Cookie、Authorization、查询中的令牌、表单内容、个人信息和内部业务数据。
- 不主动扫描无关子域、端口或后台接口。

## 4. 版权与品牌

- 原始源码、字体、图标、图片和插画保留许可证、来源和授权说明。
- 严格复刻设计参数不等于自动拥有商标、Logo、专有插画、受限字体或原站文案的使用权。
- 另一个业务默认复用设计语言，不复用品牌身份和真实数据；用户明确授权时除外。
- 不确定授权时写入 `quality/gaps.md` 与 TODO，提供可替换方案，但不得把替代品描述为精确复刻。

## 5. 隐私与清理

- 截图出现姓名、邮箱、手机号、头像、地址、订单或健康/财务信息时，原件是否保留应服从用户授权和最小必要原则。
- 必须脱敏时，原件放在受控位置；公开档案中只放派生脱敏版本，并记录处理方法。
- 任何秘密一旦误入档案，应立即停止扩散、告知用户并按其指示移除；不要在日志中重复秘密值。

## 6. 探索日志

每次主动探索记录：工具与版本、命令/脚本、时间、访问范围、是否登录、是否执行页面交互、产生的文件和限制。日志本身不得包含凭据或隐私内容。
